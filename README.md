🚀 Skill Genome – Decode Your Technical Skills
Skill Genome is a full-stack web application that analyzes technical skills using resume parsing and assessments. It helps users identify skill gaps and improve their career readiness.
🔗 Live Demo: https://skill-genomex.onrender.com/
📂 GitHub: https://github.com/Abhishuuniyal/Skill-genome.git
📌 Features
🔍 Resume Analysis (Keyword Matching)
🧠 Skill-Based Test System
📊 Dashboard with Performance Insights
🔐 Authentication System
☁️ Deployed on Cloud
